## 项目概要

产品以 **Calm → Clarify → Act** 三段式体验为主线，把亲密关系中的表达困难拆成可被产品接住的步骤：先降情绪唤醒，再澄清真实需求，最后落到具体动作。

核心设计主张：

- **让表达被看见**：把「说不出口」转成可操作的低门槛交互，而不是让 AI 替用户说话。
- **四种低门槛的亲密互动**：让抽象的表达变成可感知的动作。
- **AI 负责理解材料，程序掌握流程**：前端、AI 服务与硬件协作的边界划分。
- **先验证可操作，再验证是否有效**：理论提供设计线索，但不代替证据。
